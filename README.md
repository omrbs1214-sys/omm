# Nox Menu (Fabric mod for Minecraft 26.2)

Client-side mod for Nox Launcher.
- Animated 3D character (your skin + cosmetics) on the title screen and pause screen, left side.
- "Cosmetics" button on those screens + press Right Shift in-game to open the cosmetics menu.

## Build it with GitHub (no install needed)
1. Make a free account on github.com, then create a NEW PUBLIC repository named `nox-menu`.
2. Upload everything in this folder (including the hidden-looking `.github` folder) to that repo.
   Easiest: GitHub Desktop, or "Add file -> Upload files" and drag the folder contents in.
3. Open the repo's **Actions** tab. A build named "build" starts by itself (3-6 minutes).
4. When it shows a green tick, open **Releases** on the right: you will see `nox-menu.jar`.
5. In Nox Launcher -> Settings -> NOX MOD, type `yourname/nox-menu`, press Save, then Play.
   The launcher downloads the newest jar before every 26.2 launch.

Manual way: download `nox-menu.jar` from Releases and put it in `C:\Users\<you>\.noxlauncher\nox-mod\`.

If the build fails: open the failed run in Actions, copy the red error text and send it to Claude.
